# silentvoice-links

Permanent redirect links behind the QR codes on The Silent Voice poster.

| QR code | Link | Goes to |
|---|---|---|
| GitHub Repository | https://suyogkad.github.io/silentvoice-links/repo/ | set in `links.js` |
| Demo Video | https://suyogkad.github.io/silentvoice-links/video/ | set in `links.js` |
| Live Project | https://suyogkad.github.io/silentvoice-links/live/ | set in `links.js` |

**To change a destination:** edit `links.js` on GitHub and commit. The printed QR codes never change.

**To track scans:** make a free site at goatcounter.com and set `GOATCOUNTER` in `links.js` to its code.
